# Scionos Capture 1.1.0

## Français

Cette version corrige les décalages observés sous Windows avec mise à l’échelle du texte, zoom fractionnaire et barres de défilement classiques. Elle gère les éléments fixes et collants, les conteneurs internes, les pages dont la mise en page change, et transfère les grandes captures par fragments persistants sans quitter l’appareil. La capture temporaire est supprimée dès son décodage par l’éditeur.

Téléchargez `scionos-capture-v1.1.0.zip`, vérifiez le fichier SHA-256, extrayez-le puis chargez le dossier dans Chrome ou Edge.

## English

This release fixes capture misalignment on Windows with text scaling, fractional zoom, and classic scrollbars. It handles fixed and sticky elements, internal scrolling containers, changing layouts, and transfers large screenshots through persistent local chunks. Temporary captures are deleted as soon as the editor decodes them.

Download `scionos-capture-v1.1.0.zip`, verify the SHA-256 file, extract it, and load the folder in Chrome or Edge.

## Español

Esta versión corrige la desalineación en Windows con escalado de texto, zoom fraccionario y barras de desplazamiento clásicas. También gestiona elementos fijos o adhesivos, contenedores internos, diseños cambiantes y capturas grandes mediante fragmentos locales persistentes.

## Deutsch

Diese Version behebt Verschiebungen unter Windows bei Textskalierung, gebrochenem Zoom und klassischen Scrollleisten. Sie verarbeitet feste und klebende Elemente, interne Scrollcontainer, veränderliche Layouts und große Aufnahmen über persistente lokale Fragmente.
