# Scionos Capture 1.0.0

## Français

Première version officielle de **Scionos Capture** par **eyelo SA** (ScioNos). Cette extension Manifest V3 respectueuse de la vie privée permet la capture d'écran visible, de page entière, de zone sélectionnée et de zone défilante, avec un éditeur d'annotation complet (formes, flèches, texte, floutage, recadrage), le nouvel export de rapport HTML interactif autonome, le logo officiel SN et la prise en charge de 4 langues (FR, EN, ES, DE).

Téléchargez `scionos-capture-v1.0.0.zip`, vérifiez son fichier SHA-256, extrayez-le puis chargez le dossier dans `chrome://extensions` ou `edge://extensions` en mode développeur.

## English

First official release of **Scionos Capture** by **eyelo SA** (ScioNos). This privacy-first Manifest V3 extension features visible tab capture, full page capture, selection capture, and scrolling area capture, with a complete annotation editor (shapes, arrows, text, blur, crop), interactive standalone HTML report export, the official SN brand logo, and 4-language support (FR, EN, ES, DE).

Download `scionos-capture-v1.0.0.zip`, verify its SHA-256 file, extract it, and load the folder from `chrome://extensions` or `edge://extensions` in developer mode.
